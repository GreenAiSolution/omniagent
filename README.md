# Omniagent

**One agent. Every channel. Every job.**

AI staff for your business's WhatsApp number — answers customers across text,
voice notes, photos and documents, grounded only in your own knowledge with the
source cited, and takes real actions gated behind a typed **CONFIRM**.

This repo is the marketing site, served via GitHub Pages:

- **[The site](https://greenaisolution.github.io/omniagent/)** — agents, night
  shift, the assemblies, pricing, and a live sandbox demo.
- **[The System](https://greenaisolution.github.io/omniagent-system/)** — the
  application-only flagship tier.

The engine itself — the workflows behind the agents — is not distributed here.
It's what you receive, deployed and running on your number, when you take a
plan or an assembly. **Book a demo on the site.**
